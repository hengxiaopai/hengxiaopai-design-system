# Hengxiaopai Design System

Design decisions, visual grammar, motion grammar, prompt DSLs, assets, and examples for the Hengxiaopai design system.

## Structure

- `01-design-decisions/` - principles and decision records
- `02-design-skills/` - designer and studio style references
- `03-visual-grammar/` - layout, typography, spacing, cards, and hero rules
- `04-motion-grammar/` - motion behavior for hero, hover, scroll, cursor, and transitions
- `05-assets/` - reusable visual asset categories
- `06-prompt-dsl/` - prompt patterns for supported builders
- `examples/` - sample applications and interface patterns
